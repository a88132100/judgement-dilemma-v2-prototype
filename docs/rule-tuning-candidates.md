# 規則調整候選清單

## 使用原則

此文件只列出未來可調整的規則旋鈕，不代表現在要修改。

任何調整都應遵守：

- 一次只調整一到兩個變數。
- 調整後重新跑模擬。
- 調整後至少做一輪人工流程回歸。
- 若影響玩家可理解性，先更新文件與測試。

## 目前建議

暫不調整核心數值。

理由：

- 11 點勝利門檻已定案。
- 真人流程測試沒有明顯流程問題。
- 目前更需要觀察 UI/美術整合後的可讀性與 Bot 發言壓力。

## 可調整旋鈕

### 勝利與節奏

#### 勝利門檻

- 目前值：11。
- 可測替代：12。
- 觀察指標：
  - 平均回合數是否過長。
  - 回合上限結束比例是否過高。
  - 玩家是否覺得快要贏時仍有壓力。

#### 回合上限

- 目前值：10。
- 可測替代：8 或 12。
- 觀察指標：
  - 遊戲是否太短而無法形成心理博弈。
  - 遊戲是否太長而導致決策疲乏。

### 承諾壓力

#### 守諾獎勵

- 目前值：+1。
- 可測替代：+2。
- 可能效果：
  - 提高守信策略吸引力。
  - 降低背叛的相對收益。

#### 失信懲罰

- 目前值：-1。
- 可測替代：-2。
- 可能效果：
  - 強化承諾壓力。
  - 讓投機型更容易被懲罰。

### 基礎結算

#### 全員合作

- 目前值：每人 +2。
- 可測替代：+1 或 +3。
- 觀察指標：
  - 合作是否太穩。
  - 玩家是否仍願意背叛。

#### 少數背叛

- 目前值：背叛者 +2，合作方 -1。
- 可測替代：背叛者 +1 或 +3。
- 觀察指標：
  - 背叛策略是否過強。
  - 玩家是否覺得守信沒有意義。

#### 背叛過載

- 目前值：背叛者 -2，合作方 -1。
- 可測替代：背叛者 -3。
- 觀察指標：
  - 多人背叛是否仍太常出現。
  - 投機型是否勝率過高。

#### 全員背叛

- 目前值：每人 -3。
- 可測替代：-2 或 -4。
- 觀察指標：
  - 全員背叛是否成為快速出局來源。
  - 玩家是否理解全員背叛的懲罰原因。

#### 孤勇者

- 目前值：唯一合作方 +2，背叛者 -1。
- 可測替代：合作方 +1 或 +3。
- 觀察指標：
  - 孤勇者是否太容易翻盤。
  - 玩家是否把合作視為高風險高報酬選項。

### 功能牌

#### 宿命

- 目前值：命中 +2，落空 -1。
- 可測替代：命中 +1 或落空 -2。
- 觀察指標：
  - 玩家是否願意使用宿命。
  - 宿命是否變成太強的翻盤工具。

#### 庇護

- 目前值：符合條件時減少 1 點基礎損失。
- 可測替代：減少 2 點損失。
- 觀察指標：
  - 合作方是否有足夠防守感。
  - 庇護是否讓合作方太難被懲罰。

#### 反擊

- 目前值：命中背叛方 -1。
- 可測替代：-2。
- 觀察指標：
  - 背叛是否需要更高反制壓力。
  - 反擊是否造成過強懲罰。

#### 真理之眼

- 目前效果：查看目標原始選擇，並可改變自己的最終判定陣營。
- 暫不建議調整。
- 觀察指標：
  - 玩家是否理解看到的是目標原始選擇。
  - 改變自身陣營是否造成結算理解負擔。

## 調整優先順序

若之後需要調整，建議優先順序：

1. 失信懲罰。
2. 少數背叛收益。
3. 宿命命中/落空數值。
4. 回合上限。
5. 孤勇者收益。

不建議第一輪就調整：

- 真理之眼核心效果。
- 新增卡牌。
- 新增資源系統。
- 新增多人或後端。

## 觀察門檻

可用以下條件判斷是否需要調整：

- 單一人格在明確勝者局勝率超過 55%。
- 回合上限結束比例超過 45%。
- 平手比例超過 20%。
- 玩家多數認為背叛總是比較好。
- 玩家多數認為守諾沒有存在感。
- 玩家無法說明宿命或真理之眼造成的分數變化。
