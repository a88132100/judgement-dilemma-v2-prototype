## Alpha 2 目標

Alpha 2 應從 MVP 四張牌推進到完整功能牌互動驗證。

主要驗證：

- 混沌造成的最終陣營反轉與暗放牌失效。
- 鏡像對基礎結算的交換與多人衝突處理。
- 賭命的高風險背叛壓力。
- 權宜牌是否適合納入主牌庫，或應作為額外模式。
- Bot 是否能理解新卡牌的使用價值。
- Simulator 是否能測到新卡牌對勝率與節奏的影響。

## 目前 Prototype 基準

- 起始裁決點數：6。
- 勝利門檻：11。
- 出局門檻：0。
- 回合上限：10。
- 固定 4 人局：1 名真人玩家與 3 名 Bot。
- 每回合最多使用 1 張功能牌。
- 宿命在 `fateDeclare` 獨立宣告階段處理。
- 公開型功能牌目前只處理真理之眼。
- 暗放型功能牌目前處理庇護與反擊。

## 解析總原則

雲端文檔的總原則：

1. 先確定最終陣營與局勢。
2. 套用基礎結算。
3. 套用庇護、鏡像等會改動基礎結算的牌。
4. 套用反擊、宿命、賭命等額外加減點效果。
5. 最後套用守諾 / 失信。

Prototype 建議落地為：

1. `fateDeclare`：宿命宣告。
2. `playCards`：暗放陣營與功能牌。
3. `resolvePublicCards`：真理之眼，再處理混沌。
4. `reveal`：揭示原始選擇與功能牌。
5. `resolveJudgment`：
   - 根據混沌等效果確定 `judgedFaction`。
   - 判定本回合局勢。
   - 計算 `baseDeltaByPlayerId`。
   - 套用庇護、鏡像，得到 `adjustedBaseDeltaByPlayerId`。
   - 套用反擊、宿命、賭命、權宜牌額外修正。
   - 套用承諾修正。若因混沌導致承諾不一致，該玩家不拿守諾獎勵，也不吃失信懲罰。

## 已有卡牌

### 宿命

狀態：已實作。

關鍵規則：

- 所有人發言完畢後、出牌階段前宣告。
- 預言類型為勝負預言或身分預言。
- 命中 +2 裁決點數。
- 落空 -1 裁決點數。
- 判定依最終判定陣營。
- 受混沌影響時，應以反轉後結果判定。

Alpha 2 需要補強：

- 確認混沌改變 `judgedFaction` 後，宿命判定使用反轉後結果。

### 真理之眼

狀態：已實作。

關鍵規則：

- 所有玩家暗放完陣營牌後、翻牌前觸發。
- 指定 1 位其他玩家，偷看其原始陣營選擇。
- 使用者可選擇是否更換自己的陣營選擇。
- 不公開原本陣營、改變後陣營、偷看到的內容。
- 若之後受到混沌影響，最終判定仍以混沌反轉後結果為準。

Alpha 2 需要補強：

- 真理之眼更換後仍可被混沌反轉。
- 若混沌指定真理之眼使用者，混沌不應回溯取消已完成的真理之眼公開效果；只反轉最終陣營並使暗放型功能牌失效。

### 庇護

狀態：已實作。

關鍵規則：

- 暗放型。
- 自己最終判定為合作，且至少有玩家最終判定為背叛時檢查。
- 只減少基礎結算造成的損失。
- 最低減至 0，不可轉為正值。
- 不抵銷承諾失信、宿命反噬等額外懲罰。

Alpha 2 需要補強：

- 若使用者被混沌指定，庇護直接失效。

### 反擊

狀態：已實作。

關鍵規則：

- 暗放型。
- 自己最終判定為合作，且至少有玩家最終判定為背叛時檢查。
- 系統隨機選擇 1 名背叛者作為目標。
- 目標額外 -1 裁決點數。

Alpha 2 需要補強：

- 若使用者被混沌指定，反擊直接失效。

## Alpha 2 主牌庫新增卡牌

### 混沌

狀態：已實作。

類型：公開型。

建議 CardType：`chaos`

效果：

- 指定 1 名玩家。
- 被指定玩家若本回合有使用任何暗放型功能牌，該功能牌直接失效。
- 被指定玩家本回合陣營行為自動反轉：
  - 原始合作 -> 最終背叛。
  - 原始背叛 -> 最終合作。
- 翻牌時仍顯示原陣營卡。
- 結算時一律以反轉後陣營作為 `judgedFaction`。
- 混沌無法取消，也不受其他功能牌抵銷。

承諾豁免：

- 若混沌導致玩家最終判定陣營與承諾不一致，該玩家本回合不獲得守諾 +1，也不承擔失信 -1。
- 若混沌反轉後剛好與承諾一致，依一般承諾規則給守諾 +1；目前實作只豁免「原本守諾、因混沌被迫失信」的情境。

測試重點：

- 混沌反轉合作為背叛。
- 混沌反轉背叛為合作。
- 混沌使庇護、反擊、鏡像、賭命失效。
- 混沌後宿命依反轉後陣營判定。
- 混沌後承諾修正依豁免規則處理。

### 鏡像

狀態：已實作。

類型：暗放型。

建議 CardType：`mirror`

觸發條件：

- 使用者最終判定為合作。
- 本回合局勢為少數背叛。

效果：

- 系統隨機鎖定 1 名背叛者作為目標。
- 使用者與該目標交換本回合基礎結算結果。
- 交換範圍只包含基礎結算，不包含承諾、宿命、反擊、賭命等額外修正。

多人衝突：

- 若多名合作者同時使用鏡像且鎖定同一位背叛者，系統隨機判定其中 1 人成功交換。
- 其餘玩家只觸發傷害免疫效果，不扣除裁決點數。

失效：

- 若無人背叛，此牌無效。
- 若局勢不是少數背叛，此牌無效。
- 若使用者被混沌指定，此牌失效。

Prototype 裁決點版本落地：

- 目前少數背叛的基礎結算是背叛者 +2、合作者 -1。
- 鏡像成功時，使用者取得目標的 `baseDelta`，目標取得使用者的 `baseDelta`。
- 鏡像衝突失敗但觸發免疫時，該使用者的負基礎結算調整為 0。

測試重點：

- 單一鏡像成功交換基礎結算。
- 多名鏡像指定同一背叛者時只有一人交換，其餘免疫。
- 鏡像不交換宿命、反擊、賭命或承諾修正。
- 混沌指定鏡像使用者時，鏡像失效。

### 賭命

狀態：已實作。

類型：暗放型。

建議 CardType：`gamble`

觸發條件：

- 必須與背叛陣營同時暗放。
- 揭示後，使用者是唯一最終判定為背叛的玩家。

效果：

- 成功：額外 +4 裁決點數。
- 失敗：額外 -2 裁決點數，並隨機棄 1 張手牌。
- 若失敗且沒有手牌，則下回合禁止補牌一次。

限制：

- 每位玩家每場遊戲最多使用 1 次賭命。
- 若因混沌導致使用者不再是唯一背叛者，視為失敗。
- 若使用者被混沌指定，賭命失效但仍消耗「每場一次」使用限制。

測試重點：

- 唯一背叛成功 +4。
- 非唯一背叛失敗 -2 並棄牌。
- 被混沌反轉後不再唯一背叛時失敗或失效，需依確認規則測試。
- 每場最多一次。
- 沒手牌時寫入下回合禁止補牌狀態。

## 權宜牌

權宜牌建議先列為 Alpha 2B 或 feature flag，不直接放進主牌庫。

原因：

- 雲端文檔中權宜牌合計 60 張，與主牌庫 31 張描述不一致。
- 權宜牌有多張會改變抽牌、指定玩家、失信懲罰與即時加分。
- 若與主牌庫同時加入，測試結果會很難分辨是主卡牌問題還是權宜牌造成。

### 撿角

類型：公開型。

建議 CardType：`smallGain`

效果：

- 使用者立刻 +1 裁決點數。

待確認：

- 是否在公開型觸發階段立即結算。
- 若立刻達 11 點，是否立即獲勝，或等本回合結算完成後再判定。

### 信任萬萬稅

類型：公開型。

建議 CardType：`promiseTax`

效果：

- 本回合結算時，指定 1 名失信玩家額外 -1 裁決點數。
- 若本回合無失信玩家，此牌無效。
- 若有多名失信玩家，由使用者指定其中 1 名。

待確認：

- 指定時機是在出牌時先指定，還是結算時看到失信名單後再指定。
- 混沌豁免造成「不算失信」時，是否不能成為目標。

### 人情籌碼

類型：暗放型。

建議 CardType：`favor`

效果：

- 使用者指定 1 名玩家。
- 若揭示後該玩家與使用者同陣營，兩人各 +1 裁決點數。

待確認：

- 指定目標是否在暗放時選定。
- 同陣營判定使用原始陣營或最終判定陣營。依目前總原則，建議使用最終判定陣營。

### 共識

類型：公開型。

建議 CardType：`consensus`

效果：

- 若本回合合作人數 >= 3，使用者 +1 裁決點數。
- 若合作人數 < 3，使用者 -1 裁決點數。

待確認：

- 合作人數使用原始陣營或最終判定陣營。依目前總原則，建議使用最終判定陣營。
- 4 人局中合作人數 >= 3 是否過於容易觸發，需 simulator 驗證。

### 手滑

類型：公開型。

建議 CardType：`slip`

效果：

- 揭示後，使用者本回合 -1 裁決點數。
- 使用者下回合開始時多抽 1 張功能牌。

待確認：

- 多抽 1 張是否可以突破手牌上限 3。
- 若玩家下回合已出局，是否取消補牌效果。

### 雙數玄學

類型：暗放型。

建議 CardType：`evenOmen`

效果：

- 揭示階段時，若本回合背叛者人數為偶數，使用者下回合開始時多抽 1 張功能牌。
- 若背叛者人數為奇數，使用者棄 1 張功能牌。
- 若沒有功能牌可棄，改為 -1 裁決點數。

待確認：

- 背叛者人數是否使用最終判定陣營。依目前總原則，建議使用最終判定陣營。
- 多抽是否可突破手牌上限。
- 隨機棄牌或由玩家選擇棄牌。

## 建議實作順序

### Alpha 2A：主牌庫完整化

1. 擴充卡牌型別與卡牌 metadata：
   - `chaos`
   - `mirror`
   - `gamble`
2. 補牌庫生成與卡牌數量設定。
3. 補玩家狀態：
   - `usedGambleThisGame`
   - `skipNextDraw`
   - `disabledFunctionCardThisRound`
   - `chaosTargetedThisRound`
4. 實作混沌。
5. 實作鏡像。
6. 實作賭命。
7. 補 Bot 使用策略。
8. 補 simulator 指標。
9. 最後接最小 UI。

### Alpha 2B：權宜牌實驗池

1. 先加入資料與測試，不混入預設牌庫。
2. 用 feature flag 或 simulator profile 啟用。
3. 先測撿角、共識這類無目標牌。
4. 再測信任萬萬稅、人情籌碼這類需要指定目標的牌。
5. 最後測手滑、雙數玄學這類改變下回合抽牌狀態的牌。
