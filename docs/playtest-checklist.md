# Alpha 人工試玩驗證清單

## 目的

驗證玩家是否能理解《審判困境 v2》的核心壓力：公開承諾、最終陣營、守諾/失信、宿命宣告、真理之眼資訊差，以及裁決點數結算。

此清單只用於觀察與記錄，不要求測試者給出平衡結論。

## Pass / Watch / Fail 判定

### Pass

- 玩家能完成一局。
- 玩家能說出自己為什麼加分或扣分。
- 玩家有明顯策略猶豫。
- 玩家願意再玩一局。

### Watch

- 玩家能完成一局，但需要多次提醒流程。
- 玩家大致理解勝負，但無法說明功能牌或承諾修正。
- 玩家覺得有趣，但節奏或資訊可讀性有明顯抱怨。

### Fail

- 玩家無法理解承諾與最終陣營的差異。
- 玩家無法完成一局。
- 玩家完全無法理解結算。
- 玩家覺得選擇像隨機猜測，沒有策略判斷。
